解套数学 回本所需涨幅 · 纯算术

历史利润极值 & 回撤恢复 (峰值 / 谷底 / 最大回撤 / 恢复)

主口径 = 总利润（浮盈＋已实现，净化本金）：加减仓不会影响它，所以它的峰值才是"真·赚最多"那天。历史最高/最低利润 = 有快照以来的利润峰值与谷底；最大回撤 = 从利润峰到其后最深谷的跌幅（% 仅在利润全程为正时给出，否则只报金额）；距利润峰值 = 今天离它还差多少；恢复% = 从最深处反弹回来多少（100%＝已回峰值，0%＝仍在底部）。
下半区灰色 = 净值口径（市值＋已实现），仅供参考：买入会把它抬高（花掉的现金不计入净值），所以它常显示"假新高"——别把它当真峰值。
