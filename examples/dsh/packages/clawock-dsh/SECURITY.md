# Security policy — clawock-dsh

This package is part of the clawock repository and follows its
[security policy](https://github.com/KCNyu/clawock/blob/master/.github/SECURITY.md).

## Reporting a vulnerability

Use GitHub private vulnerability reporting:
<https://github.com/KCNyu/clawock/security/advisories/new>. Please do **not**
open a public issue for a suspected vulnerability, and never paste a credential,
token or API key into one.

This is a single-maintainer project. Reports are read on a best-effort basis;
there is no response-time commitment.

## Supported versions

Only the latest version of `clawock-dsh` published on
[npm](https://www.npmjs.com/package/clawock-dsh) is supported. Fixes ship as a
new release rather than as patches to older versions.
