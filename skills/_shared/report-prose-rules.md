# 开盘、午盘和收盘报告的正文

港美两市 Mode 6 共用。写之前读 workspace 的 `src/clawock/trading-prose.md`。

- **情绪面**。说哪条消息或同业变化值得留意。用 `peer_scan` 的 Top 5、持仓与同业的今日/5 日涨跌核对比较对象和场次。正文留会改变判断的差别。
- **异动归因**。先点出最影响判断的票，用 `mover_news` 中 `primary` 且 `signal=interrupt` 的一手消息核查，确有依据时带出处和时点。停牌先交代停牌。状态是 `no_recent_filing` 时查 `known_catalysts`，`index_fund_no_issuer` 看成分和板块，`degraded` 说哪份资料没取到。只有背景消息时交代还差什么证据。若 `mover_thesis` 有红线，解释它跟异动有什么关系。这是归因语境，不是操作许可。catalyst 评级只是登记策略意见。篇幅紧时先砍板块全景细节，留异动归因。
- **技术面**。读 `signal_count` 和信号明细，说哪项价格行为影响操作时机。有行情缺口时按 `quote_coverage` 点名，旧报价只能当背景。
- **操作建议**。先用 `plan_context` 做计划对账，说今天哪些动作仍按原定条件走，哪项值得重看及原因。股数和触发线由计划表给出。风险红线按账本状态说，须写风险提示时说明这次该留意的风险。
- **证据**。按报告模板用 `[[/ctx/字段/...]]` 引同代事实，需要另算时用 `clawock tool compute` 取得本次回执。引新闻用资讯行的 `|cite`，保留来源、时点和新旧状态。股数、持仓市值、浮盈金额和未成交计划的尺寸都交给数据块。
- 读者只看得到这条微信，把内部字段和管线术语翻成平时聊天的说法。长度由你自己判断，写清发生了什么就可以停。
