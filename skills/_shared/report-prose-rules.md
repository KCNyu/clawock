# 开盘、午盘和收盘报告的正文

港美两市 Mode 6 共用。写之前读 workspace 的 `src/clawock/trading-prose.md`。

- **情绪面**。说哪条消息或同业变化值得留意。异动时点出最影响判断的票，先核 `mover_news`、`halts` 与 `mover_thesis`。停牌先交代停牌；有一手催化时说这个变化为什么会影响持仓，并引用出处。只有背景消息时说你在猜什么。窗口无公告先查 `known_catalysts`；数据源没抓到就说没抓到。用 `peer_scan` 核对比较对象和场次，正文省去排行和成串的涨跌。
- **技术面**。说价格行为怎样改变操作的时机。有行情缺口时按 `quote_coverage` 点名，旧报价只能当背景。
- **操作建议**。先跟 `plan_context` 对账，说今天哪些动作仍按原定条件走，哪项值得重看及原因。股数和触发线由计划表给出。风险红线按账本状态说，须写风险提示时说明这次该留意的风险。
- **证据**。报告模板提供同代字段和新闻引用写法。引用实时消息时保留来源、时间和新旧状态；缺字段就说明缺口。必要时用本次 compute 回执。正文把内部字段、管线术语翻成平时聊天的说法。
