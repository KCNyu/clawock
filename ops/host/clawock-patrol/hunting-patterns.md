# 修掉的巡检 issue 都出在哪（开工读，和 closed-lessons.md 配着用）

`closed-lessons.md` 讲什么不该提，这份讲该去哪找：2026-09-21 到 09-28 真修掉的 `[patrol]` issue
反复出在下面八类地方。每类都给一个能跑的探针；issue 号只是例子，要看细节用 `gh issue view <N> -R KCNyu/clawock`。
这些是找问题的方向，不是提报理由；每个候选照旧先过 closed-lessons 的反证。

1. **闸在真实数据上一条都够不着**：闸、过滤或正则分支的前置条件（字段存在、市场分支、正则写法）在今天的产物里
   一行都不满足，却照样印「都对得上」。探针：对今天的真实产物数「进入判定的行数 / 总行数」并打印；是 0，
   而代码或文档又说覆盖全体，就是候选。先确认是不是故意只管一部分：#2072 机制成立，但照建议修会在港股最小价位
   上误报，所以按 not planned 关了；同一本账的 #2104 就修了。例：#2072 #2104 #2075 #1852 #1903。
2. **异常被当成正常**：`except`、默认值、`or 0`、`|| 0` 把「读不出 / 坏了 / 缺了」变成「空 / enabled / 0 / 正常」。
   探针：在 `/root/logs/clawock-patrol/scratch/` 的副本里把输入弄坏（截断 JSON、删字段、不可读），看输出是报错
   还是照常印出来。例：#2073 #2074 #2044 #2041 #2039 #2078 #2081 #2038。
3. **闸只看了一部分**：只核第一行、一个写入方、一个字段，或者拿全文做子串匹配。探针：从**写入方和渲染方**把
   进同一个产物的来源全列出来（`git grep` 写这个文件的所有调用、渲染器里每个 `text(row.get(...))` 字段），再和
   闸的输入集合做差集。例：#2077 #2049 #2126→#2139 #2099→#2135。
4. **分母、计数、窗口**：分母漏了某几类、终身计数和带窗口的读数印在同一张卡上、「持平」进了分母却不进任何
   分子、把腿数当成天数。探针：从源数据重算卡上的 a/b，按类别列出哪些行进了分母、哪些进了分子。
   例：#2056 #2058 #2064 #2012 #1908。
5. **同一个事实有两份实现**：手抄的名单、私有的判定函数、两套数字格式、从不同来源取同一段正文。探针：
   `git grep` 出同一概念的所有实现和字面名单，拿当前 registry / 持仓逐个比输出。
   例：#2080 #2076 #2046 #2051 #2036 #2016 #2050。
6. **时间与精度**：UTC 和 HKT 混用、把文件写入时间当成发布时间、把为了排序补上的 00:00 当成真实时刻、新鲜度窗口
   比实际空档还短。探针：拿一条真实记录，从生产端一路跟到印出来的地方，看时间戳和时区怎么变。
   例：#2103 #2124 #2013 #1963 #2121 #1927。
7. **机器值没有闭合的词表**：消费方的正则、映射或 CSS 词表只认生产方可能写出的一部分值。探针：从生产方代码
   把可能的值全枚举出来（字面量、模板、f-string），逐个喂给消费方。例：#2071 #2030 #2125 #1854。
8. **文档或公开文案和实现 / 真源分叉**：数字、源的个数、标签、字段属于哪一层对不上。探针：文案里每个数字和名字
   都去找代码或数据锚点重新算一遍。例：#2107 #2069 #2070 #2101 #2102 #2035 #1989。

## recent 轮：修复漏掉的兄弟项

合并的修复常常只改了 issue 点名的那一处，下一轮又在旁边找到同一个根因（#2099→#2135、#2126→#2139、
#2072→#2104、#2007→#2017）；也有修复自己带进新错的（#2119→#2124）。对标了 `Closes #N` / `Fixes #N` 的提交：

1. 按第 3 类的探针列出同一产物的所有写入方、字段和分支，看这次修复是否全覆盖；
2. 拿今天的真实数据，打印修复后的闸「检查了几条」；
3. 同根因里没覆盖到的，提一条新 issue，正文写明「#N 的修复没覆盖到这里」。这不是重复：根因相同，位置不同。
   标题别照抄 #N，查重闸是按相似度判的。

## 别改掉的长处

每条 issue 都带可以复现的现场：文件:行、今天产物里的真实值、像「09:33 的 02208 是 8.7 == 8.7」这样的数。
这是巡检最有价值的地方。这份清单只告诉你去哪找，证据要求一点不降。
