# 被关 issue 的真实案例（closed-lessons.md 的附录，按需读）

编号与 `closed-lessons.md` 对应。关闭评论原文：`gh issue view <N> -R KCNyu/clawock --comments`。

## 1. 「没人用 / 没清理 / 没校验」——其实有，只是没搜到（最常见）

- #1320 说 `memory/.tmp` 没清理：grep 只扫了 `src/`，清理器在 `ops/host/gc_sessions.py`。
- #1445 / #1447 / #1469 说信号「无人消费」：消费者在 `*_bundle`、`skills/*/SKILL.md`、`site/assets/js/`。
- #1095 说块数「无 CI 校验」：测试一直钉着，审计 grep 的是字面量，没查消费它的测试。
- #1468 说 key 没登记：`tests/test_dashboard_payload_readers.py::METADATA_KEYS` 已登记。

## 2. 读的是过去：注释、docstring、旧 issue 描述的是已经修掉的状态

- #1344 引的三行是测试文件开头的 docstring，写的是 #1078 修复**之前**的观察。
- #1287 / #1328 说「发送后写 marker 前被杀会双投」：#508 早就用 claim 机制关掉，代码注释点名了那次事故。
- #1355 是 #1291/#1296/#1307 的重报，已由 #1308 收口。

## 3. 有意设计被当成缺陷

- #1336 `void el.offsetWidth` 强制回流是目的不是代价，旁边注释写着为什么。
- #1339 / #1342 / #1351 「不尊重 reduced-motion」「!important 覆盖」：一条通配规则覆盖全部，!important 就是 reduce 模式本身。
- #1456 / #1470 「散落 / 硬编码」：跨边界契约的有意复制，抽常量反而是错误抽象。
- #1328 剩下的窗口是故意留的（#1271：漏投不能静音，重投能被看见）。

## 4. 影响是乘出来的，不是量出来的；或者修了不值

- #1318 / #1319 / #1322 / #1326 模块太大、函数太长、import 太多：事实对，但没有用户可见的代价，不排期。
- #1346 省 0ms（同链还有 4 个模块 import 同一个包）；#1359 import 238ms 量级不值；#1259 实测 27ms。
- #1347 建议的缓存会把 0.5s/天 的性能项换成一类正确性风险。
- #2072 「STALE_PRICE 对港股可达行数为 0」机制成立，但按建议补字段后，港股最小价位下的正常平开平收会被报成 WARN（当天 09:33 的 02208 就是 8.7 == 8.7），以 not planned 关闭。提「闸够不着」之前，先把修完之后会误报多少算出来。
- #1323 「无界缓存」的上界其实是磁盘上 28 个文件。

## 5. 判据红错了地方

- #1353 红是拼写拼出来的（数据里是 `catalyst`，判据写 `catalysts`）。
- #1328 判据用单行正则找跨两行的代码，红的是正则。
- #1354 判据自己崩了；#1096 看错了模块。

## 6. 架构误解：描述的机制不存在

- #1357 「驱动路径没接上」：真正的闸里根本没有那个变量。
- #1260 「加 circuit breaker」：四个调用点是四个独立的 GitHub Actions 进程，模块级 breaker 永远空转。

## 7. 同一件事拆成多条 / 重复

- #1245 / #1246 / #1249 / #1250 / #1255 是同一批展示单元的五轮「全景审计」，全部并入 #1252。
- #1135 / #1137 是 #1146 / #1153 的重复。

## 8. 产品边界外 / 需要 kcn 做产品决定

- competitor-port 31 条 NOT_PLANNED：实盘下单、OMS、HFT、RL、MLOps、超参搜索……clawock 是决策工作流插件 + 可验证 harness，**不下单、不搜参数**。
- #1119 / #1122 / #1150：方向性建议由 kcn 决定。

## 9. 把工作区里的旧副本当成线上

- #2702 「dashboard.json 停在 10-01，发布器 5 天没跑」：读的是工作区里被 gitignore 的旧文件；已发布的那份 `generated_at` 是当天。
- #2700 「发布器用了 221 小时前的汇率缓存」：221 小时的是工作区自己的 `.cache/fx_rate.json`；线上产物的汇率是当天取的、`stale: false`。
